# MW4 Fieldnotes — local HTML/JavaScript tracker

Extract the entire ZIP, then double-click **Open-HTML-Tracker.cmd**. You can also open **web/index.html** directly. The interface works offline without installation, an account, or a server. The original native interface remains in the development folder; the HTML ZIP uses this new interface.

## Using the interface

Click a Military square to mark it and every earlier Military milestone unlocked. Clearing a Military square also clears later Military milestones. Special and finish squares toggle individually. Counts update immediately and are saved in the browser. Hover still opens the requirement preview and its Track button; on a keyboard, use Enter/Space to toggle and Arrow Down to enter the preview. An unchanged automatic reading does not undo a manual correction.

- Browse or search 33 weapons in class groups. Every row shows Military/Special/finish progress, partial challenge counters, observed in-game category totals and a challenge in progress or the next unrecorded requirement. Military numbers are weapon levels; G/P/H mean Gold, Platinum and Harmonic Break.
- Open a weapon for a wide checklist with larger requirement text, numbered sections and prerequisites. Use the section shortcuts to jump to Special objectives or Gold and beyond. Switch Multiplayer/DMZ inside the checklist, then choose **Track +** beside a camo. **Next match** holds up to six pinned goals. Source notes can be expanded on each challenge.
- Use **+1**, edit counters, add notes, change requirements, or create a custom goal. Mark **Unlocked** manually when appropriate. Completion records describe what you have recorded; they are not live account data.
- The weapon's **Mastery** tab includes four Prestige presets and account mastery objectives. Season 1 Warzone objectives without confirmed targets remain disabled. These extras do not count toward the 462 base/completionist slots.
- **Reference library** contains official weapon/camo reference sheets. Some sheets show several items rather than an individual camo swatch. Three weapons use labelled placeholders where no matching official picture was sourced. You can deliberately import your own PNG, JPEG or WebP pictures (up to 10 MB each).
- **Export plan** saves checks, counters, notes and pinned goals to JSON. **Import plan** accepts HTML exports or the previous native dashboard.json, asks before replacing records, validates input and keeps one browser backup. Images and raw OCR readings are excluded from plan exports.

Manual progress is stored in this browser's localStorage; imported pictures use IndexedDB. Export backups before clearing browser data. File mode and the optional localhost companion are separate browser origins and have separate storage. Export/import your plan when switching launch modes, browsers, folders or localhost addresses. Imported pictures stay with their original browser storage. A local build can migrate existing native preferences into an empty browser store; the shared ZIP contains no personal migration data.

## Optional automatic detection on Windows

The installed **MW4 Camo Tracker** desktop shortcut opens the companion with **-StartTracking**, which starts scanning immediately. If the companion is already open, it starts a stopped watcher or keeps the existing watcher running. Use **Tracker > Stop tracker** to pause capture. The ordinary Open-Automatic-Tracker.cmd launcher still opens the controls without requesting capture automatically.

Double-click **Open-Automatic-Tracker.cmd** to open the same interface through a local Windows companion at 127.0.0.1:8777. The launcher creates the session token automatically. If the companion is already running, the launcher reopens that session without creating another server; there is no token to copy or create manually. Capture remains stopped until you click **Start tracker** in the automatic tracker controls. Windows PowerShell and built-in Windows OCR are required. The companion has a random session token, accepts requests only on loopback, and exposes fixed tracker routes. It does not connect to Battle.net or a game API.

During play, the watcher checks only a small menu-header region (about 10.5% of the window) every ten seconds. Full-window capture and OCR run only after that header identifies a camo menu, every four seconds by default. Two matching readings are required before updating local observations; allow roughly 15–20 seconds when first opening a menu. Identical frames normally skip OCR. Alt-tabbing away pauses capture. Screenshots stay in memory and are discarded; no screenshot files or growing image history are saved. Capture and OCR still consume resources, especially on animated camo menus. End-of-round weapon-level recognition is not implemented.

Confirmed readings apply automatically after two matching scans. Individual counters update only when their weapon, requirement and target identify one camo or saved goal. Military category totals record the sequential prefix automatically (for example, 2/8 marks the first two). Completed Special/Prestige groups record their unlocks automatically. Partial Special/Prestige totals and unmatched readings remain informational; no review dialog is required. A receipt for each applied reading prevents an unchanged observation from overwriting a later manual correction. Stop capture with **Stop tracker**. Five minutes without authenticated browser contact stops the watcher. **Shut down companion** stops both the watcher and local server; closing a tab alone does not immediately stop capture.

Detection requires a visible weapon header and camo keywords. It recognises individual labelled challenge fractions and progression category totals independently, including an OCR slashed zero in Special counts. Military totals mark the sequential prefix; complete Special/Prestige groups mark their unlocks. Partial Special/Prestige totals and the observed four-slot completionist total do not identify individual unlocks. Ambiguous or unsupported layouts are skipped. Borderless/windowed mode is preferable because fullscreen or overlays can return blank images. Progression recognition was validated against the supplied Han 86 screenshot and live Kastov 762 and Axion menus. A browser check using the live Axion readings confirmed all eight Military squares populated on the main page. Other layouts and general OCR accuracy/performance still need testing.

## Catalogue and source confidence

The bundled catalogue contains 33 weapons, 462 base/completionist entries, 99 Special camo names, 264 military milestones, 132 Prestige presets and 10 account mastery entries. MP/DMZ variants carry source links and confidence labels. Military entries retain official numbering where individual names were not verified. Estimated unlock levels, uncertain objectives and conflicting reports are visibly labelled. These are sourced presets, not a claim that every entry has been checked in game.

Official reference art and confirmed examples come from Activision's [progression guide](https://www.callofduty.com/uk/en/blog/2026/10/call-of-duty-modern-warfare-4-ready-for-launch-progression-prestige) and [launch weapons guide](https://www.callofduty.com/uk/en/blog/2026/10/call-of-duty-modern-warfare-4-launch-multiplayer-operators-weapons-equipment-create-a-class). Other Special objectives come from [Axolwaffles' community workbook](https://docs.google.com/spreadsheets/d/1bTeaSbvtP4tEiKPoqLKznznqnu3AzlhVouOJh1gM53w/edit), which its author explicitly invited people to copy and edit. Numeric military milestones were checked against [Dexerto](https://www.dexerto.com/wikis/modern-warfare-4/camo-tracker/) and [Upblazed](https://upblazed.com/tools/mw4-camo-tracker). Per-entry links are available in the interface. MW4.GG's database and code are not included.

Game names and official reference artwork belong to Activision and their respective owners. This is an unofficial local tracker, with no account integration or game-memory access. The capture design uses ordinary screen observation; this document does not promise a publisher's approval of third-party software.

## Sharing and validation

**MW4-HTML-Tracker.zip** is the clean application package. It excludes personal progress, OCR observations, imported pictures, source downloads and validation files. Your friend extracts it and opens Open-HTML-Tracker.cmd; send an exported plan separately if desired. Review notes before sharing.

Browser checks cover all 33 weapons, prefilled objectives, the six-goal limit, edits/persistence, MP/DMZ metadata, Prestige completion, import/export, malicious text escaping, image imports, responsive layout and direct file mode. Companion checks cover token/origin validation, path confinement and capture-disabled start/stop behavior. Progression overview recognition passed a live Kastov 762 test; general OCR accuracy and performance remain unverified.

Provided screenshot observations can be recovered into data/imported-observations.json. The companion merges these with the live watcher readings without competing writes to data/progress.json. Imported observations and the private local session file are excluded from sharing packages.

The automatic interface shows a watcher status strip directly below the header on every page, including paused, scanning, stopped and disconnected states. A recognised weapon progression heading can yield a category reading even if OCR misses the other category headers.
